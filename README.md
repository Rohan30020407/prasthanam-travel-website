# Prasthanam Travel Website

A simple travel website created using HTML5 to showcase travel-related information and pages.

## Features

- Home page
- About Us page
- Address page
- Contact Us page
- Travel destination images
- Navigation between pages

## Technologies Used

- HTML5

## Project Structure

- `index.html` - Home page
- `About.html` - About Us page
- `Add.html` - Address page
- `Contact.html` - Contact Us page
